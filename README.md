# Automated Price Tracker & Web Scraper 🛒⚡

An automated web scraping and monitoring service built with Node.js and Puppeteer. It tracks dynamic product prices in real-time and pushes instant notifications to Discord channels via Webhooks.

---

## 🚀 Key Features

* **Headless Browser Automation:** Navigates dynamic Single Page Applications (SPAs) and extracts rendered DOM data using Puppeteer.
* **Webhook Event Dispatching:** Formats and dispatches instant price alerts via Discord Webhooks using standard REST/JSON payloads.
* **Secure Configuration:** Protects sensitive endpoints and environment variables using `dotenv`.

---

## 🛠️ Tech Stack

* **Runtime:** Node.js
* **Automation / Scraping:** Puppeteer
* **Alerts:** Discord Webhooks (HTTP POST)
* **Version Control:** Git & GitHub
